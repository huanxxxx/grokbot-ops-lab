# grokbot-ops-lab

公开的运营实验账本：用 [Grok Bot](https://cursor.com) 团队跑 X「人闸日志」与微信公众号「AI圈日常」的冷启动，只沉淀**会影响下次决策**的证据与方法。

> 不承诺涨粉/爆款。这里记的是：试了什么、看见什么、继续还是停。

## 读什么（给你，也给路过的人）

1. 本页「硬约束」与「阶段目标」
2. [`playbooks/`](./playbooks/) — 已验证、可复用的动作
3. [`weekly/`](./weekly/) — 周五学习进化纪要（最多 1–2 个下周实验）
4. [`x/`](./x/) · [`wechat/`](./wechat/) — 分渠道基线、实验卡、Rejected Today

## 硬约束（人在环）

- **人发**：选题/写稿/监听 bot 只出草稿；Su 手发。不代回、不代发、不交登录态。
- **X**：额度试验窗内控量（当前 1 主帖 + 2 手回）；外来回复手接不占额度；手回前过三门禁（粘贴测试 / 四件套 / 近 48h 同作者无同文同义）。
- **公众号**：一天一次推送机会，挂在主条；正式发表与推送对象由 Su 后台点选。
- **不写**：幻想涨粉门槛、编造经历/数据、买粉互赞圈、关键词自动回。

## 阶段目标（可改，改时写进 weekly）

冷启动基线 + 人闸流水线可运转；暂不设幻想涨粉/阅读门槛。用证据定下周最多 1–2 个优先实验。

## 怎么写进这个仓

| 前缀 | 含义 | 例子 |
|---|---|---|
| `fact:` | 可复核的数字/事件 | `fact: X followers 0→6 on 2026-11-04` |
| `method:` | 已验证可复用动作 | `method: hand-reply paste-test gate` |
| `stop:` | 应停用做法 | `stop: third hand-reply to 10k+ accounts` |
| `hypo:` | 待验证假设 | `hypo: pin D5 main post lifts profile visits` |

工作日各侧增量 **≤5 条**有用沉淀（不是日报全文）。周五由运营总监合并去糟粕。
