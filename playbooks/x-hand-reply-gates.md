# Playbook · X 手回三门禁

依据：Solo Creators《Grow on X by Replying》+ 2026-11-05 `@xiaoyibotmail` 同文复发（ReplySpam 信号）。

发出前 10 秒扫一眼（粘贴包备注必须写明）：

1. **粘贴测试**：原封不动贴到同赛道任意帖下仍通顺 → 删掉重写。
2. **四件套至少一**：具体事实 / 反例 / 数字 / 短亲历（备注写清命中哪项）。
3. **近 48h 同作者**：无同文、无同义复读（交包前用公开接口拉己方最近回复比对）。

禁：Great post / So true、复述原帖、推销。不代回。
